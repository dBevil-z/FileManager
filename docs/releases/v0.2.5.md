# FileManager 0.2.5

[English](#english) · [简体中文](#简体中文)

## 简体中文

- 拖放架支持调整窗口大小。本次运行中，窗口闲置释放后再次打开会恢复调整过的尺寸。
- 暂存文件可自动换行排列，文件名最多显示两行，键盘聚焦时显示移除按钮。
- 文件选择器适应较矮的窗口，目录列表、文件列表和已选项可分别滚动。

已安装 0.2.4 的用户可在 **设置 → 关于与更新 → 软件更新** 检查并安装签名更新。手动安装可使用下方的 Linux x86_64 `.deb` 或 AppImage。请参考[更新与发布指南](https://github.com/dBevil-z/FileManager/blob/main/docs/releases.zh-CN.md)。

## English

- Resize the Drop Shelf window. It restores its size when reopened after idle cleanup within the same app session.
- Shelf items wrap across rows, filenames use up to two lines, and the remove button appears on keyboard focus.
- The file picker fits shorter windows, with separate scrolling for the folder list, file list and selected items.

On 0.2.4, use **Settings → About and updates → Software updates** to check for and install the signed update. For a manual installation, download the Linux x86_64 `.deb` or AppImage below. See the [update guide](https://github.com/dBevil-z/FileManager/blob/main/docs/releases.md).
