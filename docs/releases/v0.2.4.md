# FileManager 0.2.4

[English](#english) · [简体中文](#简体中文)

## 简体中文

首个带 Linux 安装包、签名更新源和校验和的 GitHub Release。仍为早期预览版，当前验证环境为 **Linux x86_64、Ubuntu 24.04 KDE/X11**。

### 新增与改进

- 切换菜单后继续上次的目录、详情页、筛选、视图、选择及滚动位置；支持重启恢复、关闭与重置。
- 远程存储按连接和 Bucket 恢复目录与页码，短时缓存有容量和过期限制。
- 保留已有的 MinIO/S3、阿里云 OSS、SFTP、FTP/FTPS、后台传输和目录同步预览。
- 统一官方 GitHub、问题反馈、项目文档、路线图、作者与 Releases 入口，兼容旧版作者主页默认值。
- **设置 / 关于 → 软件更新**：按需检查、版本说明、下载进度、签名验证、安装与手动重启。
- AppImage、deb 和用户目录安装使用独立更新包。用户安装原子替换并保留上一版；deb 安装由系统处理授权。
- 更新签名绑定版本号；安装及重启前检查后台任务，重启前等待浏览会话保存。

### 下载与安装

- **Ubuntu/Debian：** 下载 `FileManager_0.2.4_amd64.deb`，执行 `sudo apt install ./FileManager_0.2.4_amd64.deb`。
- **AppImage：** 下载 `FileManager_0.2.4_amd64.AppImage`，执行 `chmod +x FileManager_0.2.4_amd64.AppImage` 后运行。FUSE 不可用时可使用 `--appimage-extract-and-run`。
- **已有用户目录安装：** 使用仓库安装脚本安装本版后，可直接在应用内升级。`.bin` 是此更新方式的签名载荷，不是独立安装器。
- 下载对应文件和 `SHA256SUMS`，可用 `sha256sum --check --ignore-missing SHA256SUMS` 检查传输完整性。应用更新还会验证内置公钥和签名版本。

0.2.3 及更早版本尚无真正的更新器，需要先手动安装本版。保留本地数据与历史。详见[更新与发布指南](https://github.com/dBevil-z/FileManager/blob/main/docs/releases.zh-CN.md)。

**兼容性：** 当前包在 Ubuntu 24.04 构建，依赖对应的 glibc/WebKitGTK 基线；AppImage 不代表所有发行版均已兼容。Wayland、ARM64、RPM/Flatpak 等仍在路线图中。

## English

The first GitHub Release with Linux installers, a signed update feed and checksums. This remains an early preview, currently validated on **Linux x86_64, Ubuntu 24.04 KDE/X11**.

### New and improved

- Resume each menu's directory/detail page, filters, view, selection and scroll position. Restore across restarts, disable remembering or reset positions.
- Restore remote connection/Bucket directories and pages with bounded, expiring metadata caches.
- Includes existing MinIO/S3, Alibaba Cloud OSS, SFTP, FTP/FTPS, background transfers and directory-sync previews.
- Consistent source, issue, guide, roadmap, author and Releases links; migrate the legacy default author URL.
- **Settings / About → Software updates:** on-demand checks, release notes, download progress, signature verification, installation and an explicit restart.
- Separate artifacts for AppImage, deb and user installations. User updates replace atomically and keep the previous executable; deb authorization belongs to the system.
- Version-bound signatures, active-job checks and session persistence before restarting.

### Download and install

- **Ubuntu/Debian:** download `FileManager_0.2.4_amd64.deb`, then run `sudo apt install ./FileManager_0.2.4_amd64.deb`.
- **AppImage:** download `FileManager_0.2.4_amd64.AppImage`, run `chmod +x FileManager_0.2.4_amd64.AppImage`, then launch it. Use `--appimage-extract-and-run` if FUSE is unavailable.
- **Existing user installation:** install this version with the repository's user-install script, then upgrade in the app. The `.bin` file is the signed update payload, not a standalone installer.
- Download the relevant assets and `SHA256SUMS`, then run `sha256sum --check --ignore-missing SHA256SUMS`. In-app updates additionally verify the embedded public key and signed version.

Version 0.2.3 and earlier have no functioning updater and require a one-time manual installation of this version. Local data and history are retained. See the [release/update guide](https://github.com/dBevil-z/FileManager/blob/main/docs/releases.md).

**Compatibility:** these packages are built on Ubuntu 24.04 and depend on that glibc/WebKitGTK baseline. AppImage is not proof of compatibility with every distribution. Wayland, ARM64 and RPM/Flatpak remain roadmap items.
