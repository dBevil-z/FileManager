## 0.2.2 MinIO 账号与桶浏览验收

在独立的两个 MinIO 服务上验证了无显式地域与自定义 `lab-region-1`，均不在连接中填写 Region。root、普通本地 IAM 账号均用用户名和密码通过签名认证；普通账号可分页读取 106 个桶，受限账号仅列出 1 个授权桶，并被拒绝访问其他桶。自定义地域且没有 `GetBucketLocation` 权限的只读账号也能进入已授权桶。

按所选桶递归上传、下载约 9 MB 文件并校验内容，保留空目录；同名桶内路径不会写入其他桶。结果报告和同步预览拒绝跨桶令牌。自动化另覆盖服务端 ListBuckets 继续令牌、地域提示重签、带 XML 声明的地域响应、固定桶范围保护、受限账号直接打开、错误密码及控制台 HTML 响应，且不将密码或服务器原始错误文本写入公开结果。

浏览器通过实际登录接口验证错误提示、无 Bucket/Region 的登录、106 个桶翻页、进入/返回/直接打开，以及英文暗色 900 像素布局。

最终 0.2.2 deb 和 AppImage 均在独立原生 GTK/WebKit 窗口中用普通 MinIO 账号登录；Bucket 与 Region 均留空，成功列桶并进入自定义地域桶读取文件，原生 D-Bus 均返回 0.2.2。

## 0.2 历史内存观测

读取本应用与 WebKit 子进程的 `/proc/.../smaps_rollup`。PSS 分摊共享页；直接合计 RSS 会重复计算共享页。数据是具体负载下的观测，不是通用内存上限。

一个长时间运行的 0.1 主进程达到约 1.4 GiB PSS / 1.5 GiB RSS，进程树约 2110 MiB PSS；另发现一个旧预览流程遗留的 headless 转换器，经核对所属应用与私有配置后停止。

可重复的独立 Xvfb/D-Bus 回归使用 72 条合成 4500×3000 JPEG 路径（硬链接）、4 个目录和 24 次切换，每版使用独立状态：

| 阶段           | 0.1       | 0.2 候选  |
| -------------- | --------- | --------- |
| 初始进程树 PSS | 224.9 MiB | 161.0 MiB |
| 切换 24 次后   | 334.4 MiB | 181.4 MiB |
| 预览完成后     | 317.9 MiB | 181.0 MiB |

Shelf 隐藏约 20–30 秒后，额外渲染进程退出，进程树从 4 个恢复为 3 个；随后短时闲置约为 193 MiB PSS。

最终本机安装版在恢复的实际目录/双栏会话中测得：

- 主进程：61.0 MiB PSS / 187.9 MiB RSS。
- 完整进程树：197.2 MiB PSS / 522.4 MiB RSS，3 个进程。
- 5 秒 CPU 采样：约一个逻辑核的 0.6%。
- 后一次：197.8 MiB PSS / 523.0 MiB RSS、CPU 0.4%，主进程值保持不变。

这段短负载没有重现或完整解释旧进程数小时后的所有保留内存，仍需长期实用观察。

当前预算：缩略图 320×240、文本缩略图 2 KiB、文本预览 64 KiB、前端对象缓存 8 MiB/64 条、已完成结果最多 8 个及 16 MiB 序列化内容/15 分钟。编辑仍保留 5 MiB 文件限制并保存完整内容；普通状态轮询不携带完整扫描/报告。插件预算见 SDK。

## 安装包与升级

0.2.0 的本地 deb/AppImage 曾在隔离原生环境验证：

1. 默认 Shelf 快捷键被占用时仍可启动。
2. 已运行实例接收调用方相对目录。
3. Unicode 本地文件 URI。
4. 非 UTF-8 路径跨单实例传输。
5. Shelf 首次使用才创建原生窗口。

最终 0.2.1 deb/AppImage 均已构建并完成上述远程存储原生验收。已通过托盘退出本机 0.2.0，再以测试 deb 内的可执行文件完成用户级原子替换；新进程和 D-Bus 均确认版本 0.2.1，安装文件与测试 deb 内文件逐字节一致。旧可执行文件、桌面集成文件和一致性 SQLite 快照已备份，并提供回退脚本。

目录集合/设置值跨本次升级的哈希一致，会话、操作历史和旧数据目录原位保留；测试连接未写入用户数据库。系统默认目录应用仍为 Dolphin。

本机随后通过托盘退出 0.2.1，以经过上述验收的 deb 可执行文件升级到 0.2.2。新进程与 D-Bus 版本一致，二进制哈希与测试包一致；目录集合、设置、会话、远程连接配置哈希和操作历史数量保持一致。升级前另备份了 0.2.1 程序、桌面集成与一致性数据库快照，默认目录应用仍为 Dolphin。

本地生成校验和位于 `target/release/bundle/SHA256SUMS`；生成包与私人运行证据不进入源码版本控制。推送源码与创建 GitHub Release 是不同步骤。
