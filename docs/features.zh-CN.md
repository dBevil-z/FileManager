# FileManager Linux 功能对照

[English](features.md) · [简体中文](features.zh-CN.md)

范围以 [FileOS 参考产品指南](https://fileosmac.com/docs/) 以及本项目的 F01–F42 功能编号 为准。表格区分可用入口、实测证据与平台差异；“已接入”表示实现存在，不能当作所有场景都已验收。

| 编号 | 能力                       | Linux 实现与验证范围                                                                                                                                                           |
| ---- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| F01  | 图标、列表、分栏           | 三视图已接入，目录在前；新增最多 12 个可恢复目录标签，未激活标签不挂载浏览器；名称、修改时间、大小排序，隐藏、分组和尺寸记忆。三视图已在真实目录查看。                         |
| F02  | 多选、框选、键盘、右键     | Ctrl、Shift、框选、键盘导航、双击和上下文菜单。浏览器验证了多选及右键流程；分栏的范围选择与普通列表有差异。                                                                    |
| F03  | 自动刷新、大目录、大小统计 | 原生 GIO 监听主目录及双栏目录，网格、列表和分栏都做了虚拟化；子分栏随刷新重新加载。大目录仍需分批读取。                                                                        |
| F04  | 路径栏                     | 面包屑、地址输入、Tab 补全、错误重试、创建缺失的最后一级目录、拖放定位；原生相对路径和 URI 已验证。                                                                            |
| F05  | 搜索                       | 当前目录过滤、工作空间多根文件名搜索、快速切换器。遍历按时间和项目数设上限。                                                                                                   |
| F06  | 基础文件操作               | 新建、复制、剪切、粘贴、重复、链接、复制路径、默认应用和打开方式。核心真实目录测试和浏览器文件操作通过。                                                                       |
| F07  | 单项和批量重命名           | 替换、前后缀、编号、保留扩展名和冲突预览；测试了循环改名和重启后撤销。                                                                                                         |
| F08  | 同名处理                   | 保留两者、替换、跳过和取消；替换走回收站并验证确认时的目标。测试了多个同名源、目录别名和确认后文件换位。                                                                       |
| F09  | 队列、跨盘和恢复           | 后台任务可取消；跨盘原件保留在源盘回收站。测试了两种文件系统、只读子目录、硬链接、扩展属性和连续撤销；目标不支持必需属性时拒绝发布。                                           |
| F10  | 回收站与撤销               | 恢复到原位或指定目录，清空需确认，操作历史可恢复或暂缓；若源盘回收站已清空，跨盘撤销会保留现有目标。                                                                           |
| F11  | 双栏                       | 可调比例、交换、活动窗格和 F5/F6，目录与比例持久化。已查看实际双栏布局；快捷键同原生操作共享实现。                                                                             |
| F12  | 原生剪贴板、跨应用拖放     | GTK 支持 URI、KDE 剪切和 GNOME 文件格式；自定义剪贴板实测通过。接入原生拖入、拖出；跨应用拖放的完整流程未验收。                                                                |
| F13  | 侧栏与设备                 | 收藏管理、工作空间和书签分组、系统常用目录及挂载盘。设备从 Linux 挂载表识别。                                                                                                  |
| F14  | 文件夹符号和样式           | 自动符号、手动颜色与图标、玻璃/纯色/扁平/系统蓝、强调色；已检查深浅主题。                                                                                                      |
| F15  | 预览与 Peek                | 侧栏预览、文件信息、目录树、Space 大预览及前后切换。实际 PDF 第二页在浏览器经 Rust 后端渲染。                                                                                  |
| F16  | 文档与媒体                 | 图像、EXIF、PDF、媒体信息、文本和 Office 已接入；依赖 Poppler、FFmpeg、LibreOffice 和系统解码器。iWork 读取内嵌预览；HEIC/RAW 和部分编码不保证解码。                           |
| F17  | Markdown                   | 编辑、预览、分屏、目录、全屏、保存、还原、未保存提醒；实际文件与相对图片已验证。测试了外部修改、移走文件和重启后的多级撤销。                                                   |
| F18  | 下载概览                   | 类型/日期分组、容量统计，进入当前目录范围的重复、旧下载和安装包检查。                                                                                                          |
| F19  | 安全整理                   | 按类别复核、截图目录、可选安装包回收站和整体撤销。跳过临时下载后缀及两分钟内修改的文件；保留原 mtime 的新到文件可能不被识别为近期。                                            |
| F20  | 九类清理                   | 九类界面与按项扫描；可验证的 dpkg 残留在软件包页核对。无统一使用记录时不把应用判为闲置，不自动删除不明配置。                                                                   |
| F21  | 清理安全                   | 缓存白名单、SHA-256 去重保留一份、确认后回收、撤销。临时目录和实际界面已验证重复文件恢复。                                                                                     |
| F22  | 工作空间                   | 名称、描述、色彩、跨目录引用、文件/文件夹/链接、拖入和移除。浏览器验证了保存真实文件引用。                                                                                     |
| F23  | 工作空间管理               | 分类、视图、快速固定、最近变化、归档、排序、失联重新定位已接入，未逐项原生验收。                                                                                               |
| F24  | 自带文件选择器             | 多选、位置、缩略图、搜索及所选摘要。                                                                                                                                           |
| F25  | 书签                       | 添加表单、链接粘贴/拖入、标题和封面、标签、搜索、收藏、排序；以实际网页保存书签并检查标签。                                                                                    |
| F26  | 书签视图                   | 网格、标题、瀑布流、列表、集合和工作空间关联。集合关联的核心持久化及撤销已测试。                                                                                               |
| F27  | Drop Shelf                 | 可配置快捷键、X11 顶边与拖动检测、1–9、Holding 引用及目录固定。已验证原生窗口可打开和快捷键冲突降级；Wayland 与跨应用拖放待实测。                                              |
| F28  | 托盘、登录启动             | 系统托盘、最近下载定位、常用位置与工作空间、后台及启动项；登录启动默认关闭。                                                                                                   |
| F29  | Git                        | 分支、变更和文件定位，使用只读 Git 状态参数，禁用仓库配置的文件监视器。                                                                                                        |
| F30  | 打开方式                   | 系统默认应用、GTK 选择应用、Dolphin、终端与已安装的编辑器；路径别名支持 term/code/cursor/zed/idea。                                                                            |
| F31  | 软件包                     | apt/dpkg、Snap、Flatpak、Homebrew 和多种语言包管理器；来源、版本、大小、搜索、排序和命令导出。在本机验证 apt 清单。                                                            |
| F32  | 缓存、旧版本与使用时间     | 软件缓存、并存版本和清理命令。无可信历史时显示未知；卸载命令不会自动执行。                                                                                                     |
| F33  | AI 项目与配置              | 工具和项目识别、编辑、保存、撤销、排除个人配置的跨项目复制。只在隔离项目写入测试配置。                                                                                         |
| F34  | 用量统计                   | Claude/Codex/Gemini/Copilot/OpenCode 日志适配；日期、模型、项目和估算价格依赖本地日志与定价配置。测试了 Codex 累计记录、乱序及 Claude 缓存字段；不保证覆盖各工具所有日志版本。 |
| F35  | 本机服务                   | 本地监听端口、进程/项目、浏览器打开、明确确认后发送 SIGINT。未停止用户服务做测试。                                                                                             |
| F36  | MCP                        | 本地清单、程序检测、配置编辑/复制、默认掩盖密钥、JSONC/TOML 与撤销；测试了注释、尾逗号、其他配置和旧版本恢复。                                                                 |
| F37  | Agent 终端                 | 按项目路径启动已安装的 agent，缺失时提供官方帮助；不代替用户安装或登录外部服务。                                                                                               |
| F38  | 关于本机                   | 系统、处理器、内存、磁盘、电池、显示器与安全状态，支持隐藏设备名称；不可读取的项目显示未知。                                                                                   |
| F39  | 设置                       | 外观、访问、应用、快捷键、托盘、Shelf、索引、缓存。新增六套明暗皮肤、资源面板、轻量模式与可配置 GitHub 入口；无远程自动更新服务。                                              |
| F40  | 语言和快捷键               | 中文/英文主界面；日语、德语、法语、西语有资源入口和英语回退。部分后端及原生提示目前为中文。                                                                                    |
| F41  | CLI、URL、D-Bus、KRunner   | KDE 对应 Spotlight 工作流。验证了已运行实例导航、原生文件 URI 和非 UTF‑8 路径，以及 KRunner D-Bus 查询；不接入 Siri 和 macOS 快捷指令。                                        |
| F42  | 安装和启动                 | amd64 deb、AppImage、无需 sudo 的用户安装脚本与 KDE 启动器；仅在 Ubuntu 24.04 KDE/X11 验证。                                                                                   |

Linux 的“发送”使用 KDE Connect 或邮件程序；Apple AirDrop 和原版商店购买/授权不包含在内。详细测试证据见 [实机验证](verification.zh-CN.md)。

## 0.2 扩展

新增插件中心（随应用提供的官方目录、本地包导入、权限与摘要审核、启停/更新/卸载）、QuickJS API v1、四款独立插件、统一结果和报告导出。安装后可从文件右键菜单或插件中心运行，插件引擎不常驻。技术说明和限制见 [插件开发](plugins.zh-CN.md)，后续远程市场及 Linux 平台覆盖见 [路线图](../ROADMAP.zh-CN.md)。
