# 远程存储

[English](remote-storage.md) · 简体中文

在侧栏打开 **远程存储 → 添加连接**。填写协议、服务器和凭据，点击 **测试连接**，确认能够读取起始目录后保存。随后可以浏览、按页筛选、新建空目录，以及通过后台任务批量上传、下载文件和目录。删除需要确认，且只允许普通文件和空目录。可以把连接设成只读。

## 连接配置

| 存储                   | 服务器地址示例                            | 配置                                                                                                                                                                                                                                                               |
| ---------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| MinIO                  | `https://minio.example.com:9000`          | 选择「MinIO（账号密码）」，填写 API 地址及本地账号、密码。Bucket 和 Region 均可留空；默认按路径寻址。                                                                                                                                                              |
| AWS S3 / S3 compatible | `https://s3.ap-southeast-1.amazonaws.com` | 填写 Access Key ID、Secret Access Key 和可选会话令牌，按厂商要求选择寻址方式。Bucket 留空列桶；Region 留空自动识别。                                                                                                                                               |
| 阿里云 OSS             | `https://oss-cn-hangzhou.aliyuncs.com`    | 选择「阿里云 OSS」，填写 `cn-hangzhou`、Bucket、AccessKey 和可选 STS Token。填写地域端点，应用会添加 Bucket 子域名。使用 [OSS V4 原生签名](https://www.alibabacloud.com/help/en/oss/developer-reference/guidelines-for-upgrading-v1-signatures-to-v4-signatures)。 |
| SFTP                   | `sftp://files.example.com:22`             | 填 SSH 用户名，选择 SSH Agent、私钥文件（可带口令）或密码。应用在认证前检查系统及用户的 OpenSSH `known_hosts`；首次连接请先向管理员核对主机指纹。                                                                                                                  |
| FTP / 显式 FTPS        | `ftps://files.example.com:21`             | 填用户名和密码，匿名连接可填 `anonymous`。使用被动模式。对 FTPS，服务器需支持 `AUTH TLS` 并提供系统信任的证书；`ftp://` 使用明文。                                                                                                                                 |

地址只填协议、主机和可选端口。对象存储的起始目录是 Bucket 内的前缀，例如 `backups/2026`；文件服务器留空使用登录目录，填写 `/uploads` 使用服务器绝对路径，填写 `/` 使用服务器根目录。起始目录用于浏览范围；请用存储桶策略、服务器账号权限或服务端隔离限制访问。

连接名、地址、访问账号等配置保存在应用的 SQLite 数据库。密码、Secret Access Key、令牌和私钥口令只保留到应用退出；勾选 **在系统钥匙串中记住凭据** 后，由 Linux Secret Service 保存（例如 GNOME Keyring 或支持 Secret Service 的 KWallet）。钥匙串不可用时可以选择本次运行使用。HTTPS 和 FTPS 使用系统 CA 信任链。

## MinIO 登录与全部桶（0.2.2）

选择 **MinIO（账号密码）**，填写服务器 **API** 地址、账号和密码，点 **登录并保存**。支持 MinIO root 和本地 IAM 用户；其账号/密码分别用于 S3 的 Access Key/Secret Key 签名认证（[MinIO 用户说明](https://min.io/docs/minio/linux/administration/identity-access-management/minio-user-management.html)）。也可以直接填写 Access Key/Secret Key。此入口不执行 LDAP、OIDC 的网页单点登录。

- **Region 留空**：自动查询桶地域，兼容默认地域及自定义地域的 MinIO；只有服务端无法提供地域信息时才需要手动填写。没有配置地域时无需填写 `us-east-1`。
- **Bucket 留空**：登录后显示账号有权限列出的所有桶，支持分页、筛选本页、进入桶和返回桶列表。受限账号不会获得额外权限；没有列桶权限时，可在连接中填写已授权的 Bucket，或用 **直接打开 Bucket** 进入已知桶。
- **Bucket 填写名称**：直接进入该桶，保留旧连接行为；不能通过操作参数切换到其他桶。桶列表模式下，所选桶独立绑定目录游标、传输、结果报告和同步预览。
- **起始目录**：留空从桶根目录浏览；指定前缀时，进入任意桶后从该前缀开始。MinIO 控制台通常是 `9001` 端口，文件 API 通常是 `9000`，应以实际部署为准。

登录页验证凭据后保存；密码仍遵循会话内保留或系统钥匙串选项。列桶使用 S3 ListBuckets，支持服务端继续令牌；限制最多 100,000 个桶、单次 XML 响应 4 MiB，超限时应直接连接指定桶。

## 实现与范围

远程存储是 FileManager 内置能力。Rust 核心统一管理连接、凭据和任务；S3 与 OSS 复用 OpenDAL 的对象操作，SFTP 使用 SSH，FTP/FTPS 使用独立的文件协议适配器。前端通过现有 Tauri IPC 访问，后台队列处理传输和取消。桌面版不需要额外部署服务，QuickJS 插件也无需扩大联网或凭据权限。新增协议可以沿用这个适配层；等到有共享连接、多用户权限或独立 API 的需求，再评估服务化。

- 对象存储按前缀浏览，创建空目录时写入目录标记。MinIO/S3 支持列出账号可见的已有 Bucket，也可以固定到指定桶；当前不创建或删除 Bucket。OSS 仍需指定 Bucket。其他 S3 兼容厂商需提供 SigV4 和对应的列目录、读取、条件写入等 API；使用前请测试目标端点。
- 下载先写本地临时文件，完整后再提交，同名文件会被保留。上传先检查同名项目，S3/OSS 尝试使用服务端条件写入，SFTP 使用不覆盖的重命名，FTP/FTPS 在重命名前再次检查。FTP 缺少可移植的条件重命名；OSS 版本控制开启或暂停时也会忽略禁止覆盖条件（[PutObject](https://www.alibabacloud.com/help/en/oss/developer-reference/putobject)、[CompleteMultipartUpload](https://www.alibabacloud.com/help/en/oss/developer-reference/completemultipartupload)）。这些场景应避免多个客户端同时写同一路径。
- 对象上传上限为 80,000 MiB（8 MiB 分片 × 10,000），文件名须能用 UTF-8 表示。FTP 目录如无法完整核对名称，将拒绝上传以免误覆盖。当前未提供自动同步执行、覆盖式镜像、断点续传、隐式 FTPS 或本地挂载。
- 本地验证覆盖 MinIO、SFTP、FTP 和显式 FTPS 的目录操作、空文件与 9 MiB 文件往返、同名保护和内容哈希，也验证了原生文件选择器和钥匙串凭据重启恢复。自动化测试另覆盖 OSS V4 请求、凭据隔离、中止 S3 分片上传，以及下载失败或取消后的清理。阿里云真实 Bucket 仍需用目标环境验收。

## 批量文件与目录传输（0.2.1）

- **上传文件** 可多选文件；**上传文件夹** 可多选目录，保留目录名、子目录和空目录。远程列表支持跨页勾选，再点 **下载所选**；同一批选择父目录和子项时，子项会自动去重。
- 每次最多选择 1,000 项，递归展开后最多 100,000 项、64 层。传输前完成范围扫描，遇到无法完整解析的远程条目会停止计划，避免把不完整列表当成完整目录。选择的目录含符号链接或特殊文件时会拒绝该批计划。
- 已有目录可合并，已有文件始终保留。单个文件失败后继续其他项目；上级目录失败时跳过其子项。**查看逐项结果** 可查看路径、成功或失败原因，并筛选失败项。取消后保留已完成文件，清理当前未完成文件；已创建的空目录可能保留。
- 下载通过目录文件描述符定位子目录，拒绝沿途符号链接。上传会复核扫描时的文件身份、大小和修改时间，再在传输结束时检查源文件是否改变。
- 结果保留 15 分钟，最多 8 份、合计 200,000 条记录；任务状态轮询只携带摘要。传输中退出应用会中止任务，上传清理受服务器和网络状态影响。

## 远程目录分页（0.2.1）

目录按服务器返回顺序读取，每页 100 项，**下一页** 继续远程游标，超过 5,000 项仍可继续浏览。S3/OSS 沿用服务器分页令牌；SFTP/FTP 保留目录流的位置。**筛选本页** 只筛选已读取的当前页，不代表整个目录搜索。

界面最多缓存最近 20 页以支持后退，选中项可跨页保留。切换目录或刷新会重新开始；远程目录持续变化时应刷新以取得新的列表。游标空闲 5 分钟后失效，最多保留 16 个活动游标，关闭页面会主动释放。

## 目录同步预览（0.2.1）

打开目标远程目录，点 **同步预览**，选择本地目录和比较方向，再点 **开始扫描**。比较包含双方的相对路径、文件大小和修改时间（容忍 2 秒精度差），列出仅本地、仅远程、大小差异、时间差异、类型冲突、上级目录冲突和不支持的项目，可筛选结果与路径并分页查看。预览支持取消，只读取目录信息，不执行上传、覆盖或删除。

相同大小与接近的修改时间不能证明内容相同，界面会显示 **大小相同，内容未校验**。预览是一份扫描快照，不是跨服务器的事务快照；执行传输前需重新确认目标范围。扫描超过 100,000 项、64 层，或远程条目无法完整解析时，整次预览失败，不会用部分列表判断缺失项。预览最多保留 15 分钟、4 份、合计 200,000 项，关闭弹窗会释放结果。

0.2.1 在隔离的 MinIO、SFTP、FTP 与显式 FTPS 上验证了递归传输、空目录、9 MiB 文件内容校验、冲突后继续、符号链接拒绝和每种协议 6,007 项连续翻页。真实云厂商端点仍需在目标环境联调。
