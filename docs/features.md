# Feature matrix

[English](features.md) · [简体中文](features.zh-CN.md)

The original scope follows the public [FileOS guide](https://fileosmac.com/docs/), with Linux implementations tracked as F01–F42. This table separates implemented entry points, observed verification, and platform differences; an available feature is not a claim that every desktop scenario is certified.

| ID  | Capability                    | Implementation and verification scope                                                                                                                                                                                                              |
| --- | ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F01 | Icons, list, columns          | Folder-first browsing, sorting, grouping, hidden files, sizes, and up to 12 restored folder tabs. Inactive tabs do not mount hidden browsers. All three views have been inspected on actual directories.                                           |
| F02 | Selection and menus           | Ctrl/Shift selection, marquee selection, keyboard navigation, double-click, and context menus. Multi-selection/menu flows were exercised in the browser; column range selection differs from list view.                                            |
| F03 | Refresh and large directories | GIO watches active pane directories; all three views are virtualized. Child columns reload after changes. Larger directory reads still need expanded pagination.                                                                                   |
| F04 | Path bar                      | Breadcrumbs, direct entry, Tab completion, suggestions, error recovery, creation of a missing final directory, and drop navigation. Relative paths and native URIs were tested.                                                                    |
| F05 | Search                        | Directory filtering, multi-root workspace filename search, and quick switching. Traversal has time/item budgets.                                                                                                                                   |
| F06 | Basic operations              | Create, copy, cut/paste, duplicate, link, copy path, default open, and open-with. Real temporary-directory tests and browser operations passed.                                                                                                    |
| F07 | Batch rename                  | Replace, prefix/suffix, numbering, extension preservation, and conflict preview. Cyclic renames and restart-safe undo were tested.                                                                                                                 |
| F08 | Name conflicts                | Keep both, replace, skip, cancel, and per-file resolutions. Replacements go to Trash and validate the reviewed target version. Tests include aliases, duplicate source names, and stale confirmations.                                             |
| F09 | Queue and cross-volume work   | Cancellable jobs; cross-volume originals retained in source-volume Trash. Tests cover two filesystems, read-only trees, hard links, xattrs, metadata preservation, and consecutive undo.                                                           |
| F10 | Trash and undo                | Restore to original/chosen locations, reviewed emptying, and recover/defer operation history. Missing cross-volume backups leave the existing destination intact.                                                                                  |
| F11 | Dual panes                    | Adjustable split, swap, active-pane navigation, F5/F6, and restored paths/split. Layout and shared operations were exercised.                                                                                                                      |
| F12 | Clipboard and drag/drop       | GTK URI, KDE cut, and GNOME file formats; a separate test selection passed native round trips. Native drag entry/exit is implemented; complete cross-application acceptance remains pending.                                                       |
| F13 | Sidebar/devices               | Favourites, workspace/bookmark groups, common directories, and mounted filesystems. Devices come from Linux mount information.                                                                                                                     |
| F14 | Folder appearance             | Automatic/manual symbols, per-folder colours, glass/plain/flat/system styles, and accents. Light/dark appearances were inspected.                                                                                                                  |
| F15 | Preview and Peek              | Sidebar content/info, directory trees, Space preview, navigation, and info panels. PDF page two was rendered through the real Rust backend.                                                                                                        |
| F16 | Documents/media               | Images, EXIF, PDF, media information, text, and Office previews. Poppler, FFmpeg, LibreOffice, and system codecs are optional dependencies. iWork uses embedded previews; HEIC/RAW/codec coverage is not guaranteed.                               |
| F17 | Markdown                      | Edit/preview/split, outline, fullscreen, save, revert, unsaved-change handling, and local images. External changes, moved files, and restart-safe multi-step undo were tested. Large preview rendering is bounded while editing retains full text. |
| F18 | Download insights             | Type/date grouping, category sizes, and scoped duplicate/old-download/installer checks.                                                                                                                                                            |
| F19 | Reviewed organization         | Category plans, screenshot destination, optional installer Trash, and undo. Recent mtimes and temporary download suffixes are skipped; preserved old mtimes can limit recency detection.                                                           |
| F20 | Cleanup categories            | Nine category screens and per-item scans. Verified dpkg residual entries can be reviewed in Packages. Unknown usage does not become an inactivity verdict.                                                                                         |
| F21 | Cleanup protections           | Cache allowlists, SHA-256 duplicate retention, review, Trash, and undo. Duplicate recovery was tested in temporary directories and the UI.                                                                                                         |
| F22 | Workspaces                    | Names, descriptions, colours, cross-directory file/folder references, links, drop/add/remove. Real reference persistence was exercised.                                                                                                            |
| F23 | Workspace management          | Categories, views, pins, recent changes, archive, ordering, and broken-reference relocation. Not every path has independent native acceptance evidence.                                                                                            |
| F24 | File picker                   | Multi-selection, places, thumbnails, search, and selection summaries. Used in report export and package import.                                                                                                                                    |
| F25 | Bookmarks                     | Forms, paste/drop, metadata/cover retrieval, tags, search, favourites, and sorting. Real metadata/tag persistence was checked.                                                                                                                     |
| F26 | Bookmark views                | Grid, title, masonry/list, collections, and workspace links. Associations and undo have core tests.                                                                                                                                                |
| F27 | Drop Shelf                    | Configurable shortcut, X11 edge/drag detection, 1–9 keys, Holding references, and pinned directories. Native creation, shortcut collision handling, and idle destruction were tested; Wayland and full drag workflows remain pending.              |
| F28 | Tray/startup                  | System tray, recent downloads, places/workspaces, background operation, and optional login startup. Login startup defaults off.                                                                                                                    |
| F29 | Git                           | Branch/change inspection and file reveal, with optional index locks and configured filesystem monitors disabled for status reads.                                                                                                                  |
| F30 | Open in tools                 | Default apps, GTK chooser, Dolphin, terminals, installed editors, and term/code/cursor/zed/idea aliases.                                                                                                                                           |
| F31 | Package inventory             | apt/dpkg, Snap, Flatpak, Homebrew, and language package managers; source/version/size/search/sort/command export. apt inventory was inspected locally.                                                                                             |
| F32 | Cache/version/usage           | Package caches and parallel versions with exported cleanup commands. Unknown history remains unknown; uninstall commands are not auto-executed.                                                                                                    |
| F33 | AI configuration              | Tool/project detection, editing, save/undo, and project copying that excludes personal configuration. Writes were tested only in isolated projects.                                                                                                |
| F34 | Usage summaries               | Adapters for supported Claude/Codex/Gemini/Copilot/OpenCode logs; dates, models, projects, and estimated pricing depend on local records/configuration. Tests cover cumulative/out-of-order/cache records, not all tool log versions.              |
| F35 | Local services                | Ports, process/project information, browser opening, and explicitly reviewed SIGINT. User services were not stopped for testing.                                                                                                                   |
| F36 | MCP                           | Inventory, executable checks, editing/copying, masked secrets, JSONC/TOML, and undo. Comments, trailing commas, unrelated settings, and restoration were tested.                                                                                   |
| F37 | Agent terminals               | Start an installed agent in a project directory; provide help for missing tools. No automatic installation or external-account login.                                                                                                              |
| F38 | System information            | OS, CPU, memory, disks, battery, displays, and readable security information. Device names can be hidden; unavailable data stays unknown.                                                                                                          |
| F39 | Settings                      | Appearance, apps, shortcuts, tray, Shelf, indexes, disk cache, six skins, resources, lightweight icons, and configurable GitHub URL. No signed remote updater.                                                                                     |
| F40 | Languages/shortcuts           | Chinese/English main interface with resource entries and English fallback for four additional languages. New tool strings, plugin metadata, and some native messages remain Chinese.                                                               |
| F41 | CLI/URL/D-Bus/KRunner         | Linux desktop workflows, warm instance routing, Unicode/native URIs/non-UTF-8 paths, and KRunner queries. No Siri/macOS Shortcuts integration.                                                                                                     |
| F42 | Install/start                 | amd64 deb/AppImage, user installer, and KDE launcher; validated on Ubuntu 24.04 KDE/X11.                                                                                                                                                           |

Linux sending uses KDE Connect or the mail application. Apple AirDrop and the reference product's store/licensing system are not part of this project. See [validation](verification.md) for test context.

## 0.2 extensions

The plugin center adds a bundled catalog, local imports, permission/digest review, lifecycle controls, QuickJS API v1, four independent tools, and consistent results/report export. Installed tools run from the center or context menus without a resident engine. See the [SDK](plugins.md) and [roadmap](../ROADMAP.md).
